# 能力与限制

当前入口为 [快速开始](QUICKSTART.md)、[实验指南](EXPERIMENTS.md)、[开发指南](DEVELOPMENT.md) 和 [贡献指南](../CONTRIBUTING.md)。当前环境和版本对应关系统一见 [版本与镜像发布](RELEASES.md#当前版本与来源)。

已验证单一镜像中的 C++ 构建及组件回归、Rust 模拟器完整源码构建、10个基础场景闭环，以及 GHCR 匿名获取与 Release 自动清单回传。后台 suite 支持 NVIDIA 和 CPU 软件渲染，选择与耗时见 [实验指南](EXPERIMENTS.md#渲染模式)。完整空机器安装、跨硬件一致性及全部进阶／压力场景尚未验收。

当前模拟器全量 Rust 单测有283通过、10失败、1忽略；同一测试产物在原运行环境中重现相同失败，没有新增失败。这些是已记录的上游配置、装甲标签和传感器测试问题，不能把镜像兼容验收通过表述为全量单测通过。测试明细与结果保留在 release/20261101-unified/。

已完成真实 PR 批准后配对实验、回传和清理；PR 服务当前主要支持算法 submodule 改动。源码测试、镜像发布和 PR 算法实验是三条不同流程，职责见发布指南。

模拟局限集中在 [实验指南](EXPERIMENTS.md#结果的适用范围)，服务器限制集中在 [运维指南](OPERATIONS.md)。
