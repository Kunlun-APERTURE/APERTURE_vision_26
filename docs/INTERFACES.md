# 仓库职责与接口边界

Submodule固定源码组合，不改变算法/模拟器的独立设计。两者各自保留构建入口、许可证、分支与远端，可独立clone和开发；主仓库负责适配与实验。

|组件|输入|输出|边界|
|---|---|---|---|
|算法的可选sim_auto_aim入口|图像、标定、采集时间、己方姿态/位置、弹速与运行配置|瞄准角度、有效性、advice及诊断|复用算法核心；不接收目标真值；仿真入口不要求核心依赖ROS|
|集成桥/协调器|模拟器ROS图像/TF、算法消息、实验时序|算法输入与模拟器控制消息|处理帧同步、过期、角度/坐标转换及控制资格|
|模拟器|控制角度/开火授权、配置与场景|图像/TF、运动/弹丸事件与独立真值|独立渲染与物理；不调用算法内部类|
|评分器|原始帧记录、目标真值、轨迹、接触与射击事件|规则、命中/加权分数与报告|真值不回流算法决策|

协议当前由bridge.py、sync_bridge.py和sim_auto_aim.cpp共同实现，ROS字段定义在模拟器rm_interfaces；本轮不搬动协议、不改单位或时序。后续接口变更需更新配套版本并做兼容检查，不能仅凭两个仓库都能编译认定兼容。

评审应核对采集/执行时间域、坐标与角度约定、弹速语义、无效/过期命令和开火取消、事件终结与评分。图像/姿态时间对齐与目标真值仅离线的约束保持原样。

无需新增共享协议仓库或互相链接源码。未来需要抽取适配器时另行设计，不与这次Git组织变更混合。
