# 团队视觉验收

每次优化保留一份左右对照：左优化前、右优化后；同算法干预之外的场景、种子、物理、评分与时序应一致。模型修正对照须明确唯一干预为模型ID，不能标成算法性能收益。

画面包含完整计分与弹丸结算、原图/检测瞄准、实际命中靶样、精确/加权成绩、云台误差/估计位置/目标运动参数曲线。采用源时间戳同步，不取未来帧，不补造落点；缺帧明确标注。保留最终结果与源输入/渲染摘要，导出完成不自动标记人工通过。

最终采集使用`--stage final --evidence full`。后台原始图像与离线媒体分开保存；媒体渲染在采集空闲时运行。先查看队列状态，再通过以下入口检查参数：

```bash
python3 docker/auto_aim/review_video.py --help
```

导出控制器为`review_video.py`，常规入口要求已完成的不可变配对study及封存摘要。历史研究和本轮模型纠错的视频另有专用派生导出脚本，不能绕过普通配对检查混用不同环境。

本阶段9.37秒视频为静止后台系数纠正对照，包含靶样和曲线；源视频摘要在[阶段证据](../../release/20261030-fidelity/README.md)。视频本体不进Git，团队审查待完成。画面相似不证明动态或物理一致，应结合部件曲线、轨迹和接触核验。
