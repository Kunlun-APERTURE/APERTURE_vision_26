# 基础／进阶分档：移动旋转测试 v1

场景用于评估3–4m/s平移与车体旋转叠加工况。历史v3/R4研究使用固定算法和环境；通用车辆模型尚未完成舵轮动力学实车标定。

## 按需选择

```bash
# 默认基础档；仅查看选择，不启动实验。
./sim.sh experiment suite --list
./sim.sh experiment suite --tier advanced --list
./sim.sh experiment suite --tier advanced --cases variable,turn04 --list
./sim.sh experiment suite --tier advanced --cases variable,pursuit --pressure --list

# 研究入口：需要已有v3/R4冻结包，先阅读下方执行边界。
# 使用全新输出目录，不要复用归档研究目录。
python3 docker/auto_aim/movement_study.py --tier advanced \
  --output docker/auto_aim/experiments/my-movement-study
# 同样可用 sim.sh experiment suite；恢复时必须保持相同档次、项目与pressure选择。
```

`--tier basic|advanced` 默认basic，`--cases` 为逗号分隔项目列表。进阶项目为 `variable,turn08,turn04,spin_startstop,pursuit`；基础档选择具体场景名。`--pressure` 仅在进阶档生效，只扩展variable和pursuit到±6rad/s；不自动对全部项目做参数笛卡尔积。

基础档保留静止、匀速、90°变向、正反转、自车移动六项原场景，并新增3、4m/s各自叠加±3rad/s的四项基础组合。进阶档和压力项单独展示，不与基础成绩混成一个总分。旧highspeed-v1不包含新项目。

## 固定项目

这些组合场景计分9秒：1秒静止，随后4个2秒运动阶段；完整保留原弹丸结算。世界坐标速度指令由0.1秒分段构成，经过原物理和速度伺服，不写入目标位置，不读取实际运动反馈来改变测试路线。预计算路径随机种子固定，传感器噪声种子独立登记。

| 项目 | 平移与旋转 | 路线 |
|---|---|---|
| variable | 3→4→3→4m/s，始终±3rad/s | 参考半径6.5m圆弧 |
| turn08 | 指令4m/s、±3rad/s，每0.8秒改变方向 | 前半段45°、后半段90°变化，预计算切向摆动 |
| turn04 | 指令4m/s、±3rad/s，每0.4秒改变方向 | 与turn08相同规则，频率独立 |
| spin_startstop | 指令4m/s，角速0→±3→0→±3rad/s | 参考半径6.5m圆弧 |
| pursuit | 目标/己方速度3.5/4→4/3.5→3.5/4→4/3.5m/s，目标持续±3rad/s | 双方固定方向0→45→90→45°，初距6.5m，交替追近/拉远 |

每类正反转均保留。variable/pursuit的压力项保持路线和速度，只将持续角速度改为±6rad/s。普通弧线、变向及追击的理想路线均事先检查在5–8m带内；实际距离仍以物理记录为准。

## 验收分层

1. **证据有效性**：沿用完整时段、物理真值覆盖、图像、弹丸事件、组件健康与源哈希检查。研究短测另行要求单次完整试验≤40秒（不是通用lockstep的默认预算），5Hz advice、25m/s无阻力、枪口起点、30帧暖机、session检测历史不变。
2. **实际难度**：在同一时刻要求目标速度、带正负号的角速度、己方速度都进入目标±15%范围，零角速允许±0.3rad/s。四个运动阶段逐项要求连续保持至少1秒；5–8m带累计覆盖至少80%。不能把不同时间分别达速、达转速当成组合运动达标。
3. **高频变向**：逐指令记录下一指令到来前是否进入目标方向±10°、响应时间、实际转角和最低速度；要求至少75%指令完成方向响应，运动时段速度中位数至少3m/s。0.5秒原伺服防抖及加速度限制保持不变；工况未达标是明确结果，不删记录、不改脚本重跑以过线。
4. **射击效果**：全程、起步/各阶段、变向后0–0.5/0.5–1秒、距离分组及联合达标时段分别报告精确/加权命中、命中每秒和样本量；零射击照常显示。最长实际命中间隔（另保留按发射时刻的诊断）、跟踪暂失、切板、模型接管/释放、命令跳变作为诊断。高频相邻事件窗口可以重叠，只作逐事件分析，不把重叠窗口累加成独立样本。

新难度先建立能力基准，不套用旧低难度分数作为必须通过的准确率门槛。三种子配对区间仅描述，不构成一轮新的优化通过；难度失败和算法低分都保留。


## 执行边界

研究控制器需要既有v3/R4冻结包及历史资料。新机器先用README中的单场景命令验证环境，不能直接运行旧研究并继承其验收。按需选择项目，采集前冻结条件与种子；完整视频按REVIEW_VIDEO.md准备，实际难度和射击成绩分开。
