# 仿真自瞄鲁棒性 v3

算法保持 ROS 独立。所有目标真值、物理装甲身份及命中结果仅由独立评分器读取。
当前默认仍是 `legacy`；`tracking_v3` 为检测与跟踪候选，`tracking_fire_v3` 在同一跟踪算法上使用新的开火门控。人工视觉确认与规则验收分别记录。

## 运行与证据

```bash
# 单次 advice 射击，发射间隔至少 0.2 秒，完整用时最多 40 秒。
./sim.sh experiment run --scene random_both_10 --mode shoot --matrix single \
  --algorithm-profile tracking_fire_v3 --gimbal-profile feedforward \
  --seed 2026102001 --repeat 1

# 执行可恢复的独立种子对照；源码、配置、模型或镜像变化需新建输出目录。
python3 docker/auto_aim/robustness_study.py --phase validation \
  --profiles tracking_v2 tracking_fire_v3 --output /path/to/study/validation

# 原始 JPEG 通过真实检测/解算/跟踪回放，无控制输出。
python3 docker/auto_aim/robustness_replay.py --run RUN_ID \
  --profile tracking_v3 --output /path/to/replay

python3 docker/auto_aim/robustness_report.py --study /path/to/study
```

原图回放输入为既有 `input.mjpg`、`frames.jsonl` 与 `telemetry.jsonl`。没有原图的开头准备帧会明确标记为历史观测回退，不算原图推理验证。候选诊断记录网络初筛、NMS、类别/尺寸筛除、角点矫正、关联和更新拒绝原因；`detector_summary` 记录推理次数、尺度和图像区域。

批次采用固定源码/配置/模型/镜像摘要并保留所有无效记录。移动测量最多18秒；静止、距离静止参考和纯旋转参考6秒；弹丸结算6秒。完整单次用时包括准备、记录、结算和报告。

## 候选行为

- 网络初筛仍为0.7、新建轨迹仍使用配置的0.8置信度门槛；已有轨迹可用经过几何与创新检验的弱候选。新轨迹不继承旧轨迹的速度。
- v3 可进行最多两次推理：完整图像加640像素图像区域。缓存成功区域，轮询可覆盖全图的区域恢复小目标，并在融合时去除重复装甲。
- 灯条矫正使用局部颜色优势、短灯条几何与像素端点；拒绝白色图案和绿色弹丸颜色。失败时保留原网络角点。该开关可独立消融。
- 小像素目标可用固定装甲俯仰假设联合拟合平移和朝向，降低自由IPPE姿态对深度的耦合；允许按观测灯条像素长度启用，balance保持原解算，重新记录真实重投影RMS。
- 首次位置协方差与后续测量模型一致。径向过程噪声独立配置；短窗口加权速度初始化保留为候选，当前关闭。
- 类别在初始300ms内确认，连续几何轨迹保持身份，轨迹重建后重新确认。
- 新开火门控分别累计新鲜连续跟踪的稳定时间、检查当前双轴对齐和姿态新鲜度；未对齐时不发射，姿态过期清空稳定计时；横向窗口由预测装甲投影宽度限制，默认最多1度、取投影半宽90%。短暂缺测不发射，最多100ms保留已建立的稳定资格，恢复可信更新且指令连续时复用。姿态过期、真实指令跳变、时间异常与代次变化清空资格。

配置位于 `configs/simulator.yaml` 的 `robustness_v3`。`multi_scale_search`、`color_refinement` 仅作用于 v3；旧配置与旧调用接口兼容。底盘控制、云台配置、枪口和命中物理保持独立。

## 解释结果

- 报告按批次隔离不同候选版本。离线候选请求、历史弹丸筛选均不能视为新策略实际命中率。
- 非旋转场景按正面装甲评价；旋转叠加按目标任意有效装甲评价。有效命中/秒使用完整测量时长。
- 原换向指标用于与旧记录对比；新随机场景另记二维速度恢复。下一次指令变化前未恢复/未命中的事件记为截断，并单独报告比例。
- 未来预测点评分须唯一匹配真实物理装甲，并补偿未来己方平移。匹配覆盖率与误差共同展示；该指标不重构弹道。
- 场景文件的速度是指令值。快速换向受到既有底盘加速度和伺服翻向限制，必须同时报告实际速度，不能以2m/s指令声称已通过实际2m/s跟踪。
- 几何可见性不等同真实像素可见性。新增距离通道通过静态场景网格检查及原图预检，曾被建筑遮挡的开发记录保留为场景设计问题。

弹丸显示通过 `--projectile-visible on/off` 切换，仅影响渲染。`--command-script` 可重放固定控制与 advice 请求，用于显示对照；这类记录标记为 `fixed_script`，不能成为算法效果基线。实际调度及发射差异仍需核对。
