- 基础10项、进阶10项，各3种子，共60轮；证据与40秒执行成本检查全部通过。
- 20项串行重复全部通过；17项双路通过。ego_right_centered、adv_pursuit_pos、adv_pursuit_neg 的逐发速度派生诊断存在双路差异，保持串行。并发资格只适用于被测产物、场景、时序及机器，不能继承到新的运行快照。
- 六场景旧 R4 / 重建 B1 对照：会话相对时间下 JPEG、输入、算法输出和逐发碰撞一致，精确与加权成绩一致。原始时钟原点、媒体尾帧与原生飞行时间诊断差异保留。
- 最终再次构建的二进制哈希变化；六场景同 JPEG 回放输出完全相同，另有最终构建闭环冒烟。
- 四项 UI 特征检查完成，完整单次26–31秒；待人工视觉审查，不宣称 UI/后台统计等价。
- 独立检出及独立队列导入冻结包，基础与进阶冒烟通过；运行未挂载旧实验目录。
- 旋转与动态追击的迁移对照视频已导出，2560×1440、30fps，包含靶样及同步曲线；源证据/最终计数/完整计分与结算检查通过。视频及镜像另行分发。

首次迁移参照选用的更早 R4 包不包含进阶生成器，运行到进阶时失败；失败记录保留。后续使用实际完成过进阶研究的 R4 包作为显式参照，不回写历史结果。
