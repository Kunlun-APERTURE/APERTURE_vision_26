# B1 / E1 算法诊断结论与后续任务

固定原 E1、B1 v3 和 NVIDIA 后端，十个基础场景各三个传感器种子，共30轮522发；另做静止和3m/s正向移动旋转两个同种子重复。32轮全部完成、证据有效且弹丸完成结算。两次重复的 JPEG 序列、归一化输入／结果和逐发记录均相同。完整身份与 run_id 见 [validation.json](validation.json)。种子只改变传感器噪声，不能视为多路线泛化认证。

[成绩与计分帧统计](report.md)、[逐轮表格](trials.csv)、[诊断摘要](diagnosis.json)和[重点画面](contact-sheet.jpg)分别保存。四个完整诊断短片、逐帧记录和素材索引在本机 `exports/algorithm-diagnosis-analysis/media/`。素材来自原 JPEG，叠加诊断状态后重采样到30fps，不是算法前后对照视频。

## 已确认的观察

移动旋转场景命中率为73.9%～84.2%，但命中吞吐只有0.556～0.630次/秒；静止为4.667次/秒。低吞吐是当前主要问题之一，不能单看命中率判断完成度。

3m/s正向、反向和4m/s正向各780个计分帧，按最早失败阶段分类，未跟踪分别占405、397、383帧；未对准分别占253、232、262帧。它们的多数无检测帧仍有可见装甲，但总无检测数仅14、43、34；与频繁关联拒绝、超时重置相比，单纯“检测器没有输出”不足以解释低吞吐。

4m/s反向780帧中421帧无检测，其中只有73帧记录有可见装甲。所选最差轮次的画面显示，约4.3秒时目标已经离开视野，约7.1秒仍未回到视野。该轮3～6秒有50帧、6～9秒有87帧无可见装甲。它需要独立分析视野丢失链路，不能把全部无检测计为检测漏检。

以上是观察与代码线索，不是已完成的因果消融。关联拒绝计数包含多个候选关联，不能直接当作失败帧数。

## 优先任务 A1：定位关联距离拒绝与超时重置

证据：3m/s正向最差轮次 `20261101T123108_basic_move3_spin_pos_shoot_muzzle_no-drag_25p0_25p0_feedforward_5p0hz_tracking_fire_v3_14a332f5`，seed=2026110103。seq=68、69、71、72 在1.272～1.410秒已有 association_distance 拒绝，seq=75（1.514秒）发生 trusted_update_timeout。该轮共11次超时，145/260帧归为未跟踪；4m/s正向最差轮次共13次超时。

假设：旋转叠加平移后，预测装甲位置与真实观测的关联距离偏离，导致观测未被接受，0.25秒可信更新超时进一步触发重新建轨。尚需区分运动预测误差、位姿歧义和装甲ID匹配错误。

下一步先在冻结输入上离线回放上述拒绝前后各0.3秒，读取现有 image_association、diagnosis_poses、associations 和 filter 更新记录，结合评估真值离线确定拒绝的是正确还是错误候选。目标模块为 `Tracker::track_robust` 与 `Target::assess/update_robust`。观测不足时只增加可选诊断字段，报告候选距离、阈值与ID；不直接放宽门限。

完成标准：解释上述四个拒绝帧和首个超时的直接条件，给出一个可复现的最小回放与单一修复假设；随后用原30轮配对验证。优化目标同时报告有效更新率、超时数、错误关联、加权得分/秒和命中/秒，必须逐种子列出退步；收益阈值在修复方案确定后依据当前逐种子表预先冻结。

## 优先任务 A2：定位4m/s反向目标离开视野的首因

证据轮次 `20261101T123439_basic_move4_spin_neg_shoot_muzzle_no-drag_25p0_25p0_feedforward_5p0hz_tracking_fire_v3_8dbd8858`，seed=2026110102。seq=69（1.306秒）目标仍可见且 temp_lost；seq=155（4.285秒）和236（7.089秒）画面已无目标，tracker=lost；3.280秒及3.557秒发生可信更新超时。

逐帧定位最后可见装甲、最后有效控制和首次离开视野，比较命令角度与己方实际姿态，区分前级跟踪失效、瞄准保持/选板跳变和云台执行响应。目标模块为 Aimer 的选板/保持路径和桥接控制资格。若离开视野由前级关联失败触发，先使用A1修复再判断是否需要独立的保持策略；评分真值不得回流控制。

完成标准：给出首个视野丢失边界帧及对应控制事件，解释从可见到不可见的因果链。候选修复必须在正反向3/4m/s十二轮及全部基础回归中比较可见比例、最长丢失、重捕获时间、误跟踪和射击吞吐。

## 优先任务 A3：分析可靠跟踪期间的对准与预测误差

在A1/A2明确后分析仍处于 tracking、位姿有效但 aligned=false 的片段；3m/s正向最差轮次 seq=64（1.133秒）、121（3.107秒）、226（6.743秒）为复核入口。比较选板连续性、角度误差、预测时域和云台延迟，针对单一误差来源提出修复。

此任务不以直接放宽开火容差达标。验收同时看中心加权得分/秒、命中/秒和逐发偏差，使用同一环境、种子及冻结评分器；任何明显退步单列，禁止删除低分后补样。
